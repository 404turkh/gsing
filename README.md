# Gsing

Gsing is an iOS application for managing, signing and installing IPA files directly on your device.

## Features

- IPA library management
- IPA signing
- Sign & Install
- Certificate management
- App sources
- Downloads
- File manager
- Framework and dylib injection
- Signing customization
- App entitlements and properties
- iPad support
